# STRIKE - The Animation First CSS Framework

## About The Project

STRIKE is a fictional, ultra-lightweight CSS framework built as a submission for the Coder Army CSS Hackathon 2025. The entire project—from the multi-page website to its complex, interactive components—is built with **100% pure HTML and CSS**, with absolutely no JS.

The core philosophy of this project is that _constraint fuels creativity_. By embracing the "CSS-only" rule, STRIKE aims to prove that beautiful, performant, and highly interactive web experiences can be built without relying on heavy libraries or complex build tools. The result is a website that is not only visually engaging but also incredibly fast and lightweight.

Key Features & CSS Techniques
This project serves as a demonstration of modern, advanced CSS capabilities. The most notable features include:

\*Complex Custom Animations: The hero logo, footer, and various other elements feature custom-built @keyframes animations.

\*3D Transforms & Perspective: Hover effects on cards utilize perspective, rotateX, and translateZ to create a sense of depth and interactivity.

\*CSS-Only Interactive Components:

An interactive Documentation Tab System built using the "Radio Button Hack" (<input type="radio"> and the ~ sibling combinator).

An interactive Pricing Toggle for monthly/yearly plans, built with the "Checkbox."

A Click-to-Flip 3D Card system on the pricing page, also controlled by a hidden checkbox.

A fully functional, CSS-only Component Carousel in the documentation.

Infinite Scrolling Animations: The "Live Showcase" and "Buzz Wall" components use looping keyframe animations to create a seamless, infinite scroll effect, which is one of the best usecases of CSS.

Advanced Selectors & Pseudo-elements: Used extensively for layering animations (like the hero logo) and creating UI details without extra HTML.

Fully Responsive Design: Built from the ground up with Flexbox, Grid, and media queries to ensure a flawless experience on all devices, from mobile to tablet to desktop.
