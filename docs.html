Introduction

STRIKE is an animation-first CSS framework for the modern web. It's a lightweight, performance-driven toolkit designed to help you create stunning, fluid user interfaces with zero JavaScript.

My core belief is that constraint fuels creativity. By embracing the power of pure CSS, we can build experiences that are not only beautiful but also incredibly fast and maintainable.

This documentation is your practical guide. On the left, you'll find the core components. Each section provides a live preview and the ready-to-use code snippets you need to bring your vision to life.

Component: Carousel

A lightweight, responsive, and fully interactive carousel built with zero JavaScript. Controlled entirely by CSS selectors and state.

Animation-First

Built from the ground up for fluid, performant animations.

Featherlight

Add power, not weight. The entire framework is just a few kilobytes.

Pure CSS

Embrace the power of constraint. No JavaScript, ever.

<!-- The HTML for the STRIKE Carousel -->
<div class="carousel-container">
    <div class="carousel-slides">
        <div class="carousel-slide">...</div>
    </div>
    <div class="carousel-nav">
        <label for="slide1"></label>
    </div>
</div>


.carousel-radio { display: none; }

#slide1:checked ~ .carousel-slides {
    transform: translateX(0%);
}
#slide2:checked ~ .carousel-slides {
    transform: translateX(-33.333%);
}

#slide1:checked ~ .carousel-nav label[for="slide1"] {
    background-color: #39FF14;
}
