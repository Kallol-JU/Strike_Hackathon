Cards

The `.feature-card` component is perfect for showcasing information.

Sample Card

    <p>This is a sample card component.</p>
</div>
.feature-card {
    background-color: #1F1F1F;
    border: 1px solid #888888;
    border-radius: 12px;
    padding: 2rem;
    text-align: center;
    transition: transform 0.3s ease;
}
.feature-card:hover {
    transform: translateY(-10px);
}
